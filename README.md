FuturePOP

About the Project

FuturePOP is a simple C# desktop application that represents population data across different governorates.

We built this project primarily to practice Object-Oriented Programming (OOP) concepts in a practical setting, rather than just studying them theoretically.

---

What it does

Stores basic information about governorates (name, capital, population, etc.)
Classifies them into different types (Urban, Rural, Border, Mixed)
Organizes the data in a clean and structured way

---

Technologies used

C#
WinForms
Object-Oriented Programming (OOP)

---

Design idea

We created a base class that contains the common data shared between all governorates.
Then we added derived classes for each type.

This made the code:

cleaner
easier to manage
easier to extend later

---

How to run

Open the project in Visual Studio
Build the solution
Run the application

---

Future improvements

Connect it to a database
Improve the UI
Add charts for better data visualization

---

Notes

This project was built as a practice exercise, so it’s relatively straightforward.
The main focus was on structure and organization rather than complexity.
